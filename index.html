Fundamentos

Modelos de Linguagem de Grande Escala

Large Language Models — LLMs

Um LLM (Large Language Model) é um modelo de IA treinado com bilhões de parâmetros e vastos corpora textuais, capaz de compreender e gerar linguagem natural com alta fidelidade semântica.
📚
Treinamento
Pré-treinamento massivo
Bilhões de parâmetros ajustados sobre trilhões de tokens de texto — livros, artigos, código e web.
💬
Capacidades
Tarefas de linguagem
Sumarização, tradução, geração de código, Q&A, classificação e raciocínio em cadeia.
🏢
Exemplos
Modelos principais
GPT-4 (OpenAI), Gemini (Google), Claude (Anthropic), Llama (Meta), Mistral.

Autenticação

Chave de API — API Key

Credencial de autenticação para acesso ao serviço

🔑 A API Key é um token secreto que identifica e autoriza o acesso à API. Funciona como uma senha: sem ela, o servidor rejeita a requisição com erro 401 Unauthorized.

Boas práticas de segurança

  • Nunca inclua a chave diretamente no código-fonte
  • Não suba arquivos com a chave para repositórios públicos
  • Utilize variáveis de ambiente ou Secrets do Colab
  • Revogue e regenere se houver suspeita de vazamento
  • Monitore o uso no painel do provedor

Passo 2

Realizando a primeira requisição

Enviando um prompt e recebendo a resposta do modelo

Célula 3 — Geração de texto 
# 1. Seleciona o modelo a utilizar
modelo = genai.GenerativeModel("gemini-1.5-flash")

# 2. Define o prompt (instrução enviada ao modelo)
prompt = "Explique o conceito de Inteligência Artificial em três frases objetivas."

# 3. Envia a requisição e aguarda a resposta
resposta = modelo.generate_content(prompt)

# 4. Exibe o texto gerado
print(resposta.text)
💡 O método generate_content() encapsula toda a requisição HTTP — ele serializa o prompt, envia ao servidor e deserializa a resposta automaticamente.
Conceito-chave

Engenharia de Prompt

A qualidade da instrução determina diretamente a qualidade da resposta

❌ Prompt impreciso

prompt = "Fale sobre clima"

Sem contexto, escopo ou formato definido. A resposta tende a ser genérica e pouco utilizável.

✅ Prompt bem estruturado

prompt = """
Você é um especialista em climatologia.
Explique, em dois parágrafos acessíveis
para estudantes do ensino médio, as
principais causas das chuvas no Brasil.
"""

Papel definido + público-alvo + extensão = resposta precisa e contextualizada.

Elementos de um bom prompt: papel (persona), contexto, tarefa específica, formato de saída esperado, restrições.

Configuração

Parâmetros de geração

Controlando o comportamento probabilístico do modelo

Configuração avançada 
config = genai.GenerationConfig(
    temperature=0.7,
    max_output_tokens=512,
    top_p=0.9,
    top_k=40
)

modelo = genai.GenerativeModel(
    "gemini-1.5-flash",
    generation_config=config
)

resposta = modelo.generate_content(
    "Crie um poema sobre IA."
)
print(resposta.text)
  • temperature (0–1) — controla a "criatividade". Valores baixos = determinístico; valores altos = variado e criativo.
  • max_output_tokens — limita o comprimento máximo da resposta gerada.
  • top_p — amostragem por núcleo: considera apenas tokens que somam probabilidade p.
  • top_k — restringe a seleção aos k tokens mais prováveis em cada passo.
Chat

Conversa com histórico — chat multi-turno

Mantendo o contexto entre as mensagens da sessão

Sessão de chat com memória de contexto 
modelo = genai.GenerativeModel("gemini-1.5-flash")

# start_chat() cria uma sessão que preserva o histórico
chat = modelo.start_chat(history=[])

# Turno 1
resp1 = chat.send_message("Meu nome é Ana. Olá!")
print(resp1.text)

# Turno 2 — o modelo mantém o contexto anterior
resp2 = chat.send_message("Qual é o meu nome?")
print(resp2.text)  # → "Seu nome é Ana."

# Inspecionar o histórico completo da sessão
for msg in chat.history:
    print(f"[{msg.role:10}] {msg.parts[0].text[:60]}...")
O histórico é mantido na memória da sessão Python. Em produção, ele deve ser persistido em banco de dados para conversas de longa duração.

Implementação

Chatbot com Gemini + Gradio

Interface de chat funcional em menos de 20 linhas de código

chatbot_gemini.py — implementação completa 
!pip install -q gradio google-generativeai

import gradio as gr
import google.generativeai as genai
from google.colab import userdata

genai.configure(api_key=userdata.get('GEMINI_API_KEY'))
modelo = genai.GenerativeModel("gemini-1.5-flash")

def responder(mensagem: str, historico: list) -> str:
    """Callback chamado pelo Gradio a cada mensagem do usuário."""
    resposta = modelo.generate_content(mensagem)
    return resposta.text

# gr.ChatInterface abstrai todo o gerenciamento de UI de chat
app = gr.ChatInterface(
    fn=responder,
    title="Assistente com IA Generativa",
    description="Faça qualquer pergunta ao modelo Gemini 1.5 Flash.",
)

app.launch(share=True)  # share=True → gera link público
Avançado

Interface parametrizável com gr.Interface

Adicionando controles de entrada para personalizar a geração

gerador_texto.py — múltiplos controles de entrada 
import gradio as gr

def gerar_texto(tema: str, tom: str, paragrafos: int) -> str:
    prompt = f"""Escreva sobre: {tema}
Tom da escrita: {tom}
Quantidade de parágrafos: {paragrafos}"""
    return modelo.generate_content(prompt).text

app = gr.Interface(
    fn=gerar_texto,
    inputs=[
        gr.Textbox(label="Tema do texto", placeholder="Ex.: Inteligência Artificial na educação"),
        gr.Dropdown(["Formal", "Informal", "Técnico", "Didático"], label="Tom"),
        gr.Slider(minimum=1, maximum=5, value=2, step=1, label="Parágrafos"),
    ],
    outputs=gr.Textbox(label="Texto gerado", lines=10),
    title="Gerador de Textos com IA",
    flagging_mode="never"
)

app.launch(share=True)

Boas Práticas

Uso responsável de APIs de LLM

Orientações técnicas e éticas para desenvolvimento com IA generativa

🔐
Segurança
Proteção de credenciais
Utilize sempre variáveis de ambiente. Nunca exponha API Keys em repositórios públicos ou código compartilhado.
💰
Custo
Monitoramento de uso
Configure alertas de gasto no painel do provedor. Prefira modelos menores para tarefas de baixa complexidade.
⚠️
Confiabilidade
Validação de saídas
LLMs podem gerar informações incorretas (alucinações). Valide sempre respostas em contextos críticos.
🛡️
Resiliência
Tratamento de erros
Implemente try/except para lidar com falhas de rede, rate limits e respostas inválidas.

Principais conceitos abordados

Consolidação dos aprendizados da aula

  • API de LLM — interface que permite ao código enviar prompts e receber respostas de modelos de linguagem hospedados na nuvem, via requisições HTTP/REST.

  • Google Colab — ambiente gratuito de notebooks Python na nuvem, com suporte a GPU e biblioteca google-generativeai pré-instalável em segundos.

  • Parâmetros de geração — temperature, max_output_tokens, top_p e top_k controlam o comportamento probabilístico do modelo.
  • Gradio — framework para construção de interfaces web interativas sobre funções Python, com suporte a link público para compartilhamento imediato.
